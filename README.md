# 视频理解 · astrbot_plugin_vision

为 AstrBot 主对话模型提供两个工具：先获取视频概览，再按需要回看指定时间段。默认由主模型直接看图，也可从 AstrBot 已配置的模型中指定概览看图模型，并可选用已配置的 ASR 转写视频语音，无需在插件中另填 API Key。

## 工作方式

```text
接收视频并获取本地路径
    → 固定间隔帧 + 场景变化候选 + 边界帧
    → 邻近去重、时间覆盖检查、帧数预算
    → 默认将图片及真实时间戳交给主模型
      或由指定看图模型生成文字概览，再交给主模型
    → 证据不足时按时间点或时间段回看
```

- 概览默认每 **4 秒**采样，最终最多 **200 帧**，图片长边最多 **640 像素**。
- 概览可选独立帧或九宫格输出。九宫格每组最多 9 帧，以 PNG 无损拼接，保留正式抽帧后的像素尺寸，画面外标注帧编号和实际时间戳；详细回看继续返回独立帧。
- 超预算时增大固定间隔，仍覆盖全片，不直接丢弃后半段。
- 场景变化检测在本地完成；候选不等于编码关键帧，也不保证语义重要。
- 时间接近且内容相似时，优先保留清晰、有效的变化帧；存在明显差异或会破坏覆盖时保留必要帧。不对全片做无条件相似帧去重。
- 回看默认最多 **8 帧**、长边 **768 像素**；每个问题最多 **3 次**，多个视频共享次数。参数校验失败返还次数；处理失败或超时仍计入次数，避免无限重试。
- 直接看图模式和局部回看的真实图片通过 AstrBot 内置 Agent 的运行上下文传入主模型，每张图片前附帧信息和时间戳；工具结果返回视频信息、采样及呈现统计、警告、剩余额度和可选 ASR 转写，不重复帧明细，也不触发核心为 `ImageContent` 添加的缓存路径及“满意后发给用户”提示。
- 图片先暂存在当前 Agent 的消息缓冲中，等核心写入本批工具调用及全部结果后，再追加为独立的 `user` 图片消息，随后恢复普通消息列表。模型输入和保存历史均保持此顺序，无需修改 AstrBot 核心文件；此对接依赖当前内置 Agent 批量追加工具消息的行为。
- 视频资源提示作为当前 `user` 消息中的独立 `text` 块添加，只包含本条消息携带或引用的视频；后续消息不会重复附加缓存中的旧路径。授权有效期内仍可使用对话历史中的路径回看。
- ASR 语音增强默认关闭；开启并选择可用的语音识别提供商后，工具附带按时间分段的音轨转写。无音轨、提供商不可用或转写失败时仍返回画面分析所需的信息。

## 安装

1. 使用 AstrBot `>=4.27,<5`，将本仓库作为插件安装到 `data/plugins/astrbot_plugin_vision`。
2. 安装 `requirements.txt` 中的 Python 依赖。
3. 在 **AstrBot 实际运行环境**安装 FFmpeg，确保同时包含 `ffmpeg` 和 `ffprobe`。容器部署必须安装在容器内，而不是只安装在宿主机。
4. 使用 AstrBot 内置 Agent，确认主模型支持图片和工具调用，并启用 `video_overview`、`video_inspect`。本插件依赖 `on_agent_begin` 提供的运行上下文传入视频帧；缺少该上下文时明确报错，不支持第三方 Agent 后端。

检查依赖：

```text
ffmpeg -version
ffprobe -version
```

默认从 `PATH` 查找，也可在插件配置中指定 `ffmpeg_path`、`ffprobe_path`。路径填写可执行文件本身，不要填写带参数的命令，也不需要额外加引号。

## 使用

直接向机器人发送视频并提出问题。插件在模型请求前读取视频附件的本地路径，通过 `extra_user_content_parts` 将 `[视频理解资源]` 提示作为同一条 `user` 消息中的独立文本块添加，用户原文保留在原文本块中，不主动进行模型分析。引用消息里的视频、常见视频扩展名的文件附件也会尝试读取。

### `video_overview`

```json
{"video_path": "/AstrBot/data/temp/example.mp4"}
```

返回视频元信息、采样策略、预算是否导致降采样、实际最大采样间隔，以及按时间排序的图片。每张图片附带 `frame_id`、请求时间、实际时间和入选原因；逐帧描述不重复附带宽高。

直接看图和局部回看时，帧明细只在 `user` 图片消息中提供一次，每张图片紧邻对应说明；每组消息开头用 `tool`、`video_path` 标识来源，便于区分同批调用的多个视频。`tool` 结果不再包含 `frames`、`presentation.images` 或 `skipped_already_seen` 明细，已看过而跳过的帧仅通过 `skipped_already_seen_count` 返回数量。指定概览看图模型时，主模型不接收概览图片，因此工具结果仍保留文字概览和帧索引。

在插件配置的 **“概览看图模型（可选）”** 中，可使用 AstrBot 原生模型选择器选择已配置且支持图片的模型：

- **留空**：维持默认行为，主模型直接接收概览图片，`overview_mode` 为 `direct`。
- **已选择**：指定模型接收全部概览帧、时间戳和当前问题，生成带时间定位的文字描述；主模型只接收文字概览及帧索引，`overview_mode` 为 `delegated`。
- 该配置仅影响 `video_overview`；`video_inspect` 始终返回原图给主模型，主模型仍需支持图片输入。
- 指定模型不接收完整聊天历史、人设或工具。其描述属于二手观察，可能遗漏或误解细节，需要时应回看原图核验。
- 模型调用失败、返回空描述或超时会明确报错，**不会自动回退成主模型看概览图片**，避免意外的大量图片输入。抽帧和模型调用共用单次工具超时。

在 **“概览图片输出模式”** 中选择 `frames`（默认独立帧）或 `grid`（九宫格）。两种看图模型配置均支持九宫格：按时间顺序，每组最多 9 帧，从左到右、从上到下排列；末组不足 9 帧紧凑排列，不重复补帧。帧编号和真实时间戳位于额外标签栏，`cells` 记录每格与 `frame_id`、时间戳及行列的对应关系。同一张拼图内帧尺寸一致时，只在拼图层的 `frame_width`、`frame_height` 写一次，各格不重复 `width`、`height`；实际存在混合尺寸时才逐格记录尺寸。拼图本身的 `width`、`height` 仍表示整张画布。像素坐标 `x`、`y` 仅在拼图绘制时计算，不写入模型输入或调试输出。直接看图时，`cells` 位于每张拼图前的说明中；指定概览看图模型时，映射保留在工具结果的 `presentation.images[].cells` 中，调试输出共用相同结构。`sampling.returned_count` 仍表示帧数，`submitted_image_count` 表示实际提交给模型的图片数。

拼图保留的是 `overview_max_edge` 缩放抽帧后的像素尺寸，**拼接时不再缩放，也不重新进行有损编码**；源视频到单帧的既有缩放和 JPEG 编码步骤仍然存在。编号和边框会增加总像素，PNG 也可能比独立 JPEG 总体积更大。`max_edge_limit` 约束单帧长边，拼接画布不套用该限制，单张拼图最多 3200 万像素，超出会明确报错；请按模型的大图输入能力选择模式。九宫格可减少图片数量，但**不保证减少视觉 token 或改善细节识别**，模型服务仍可能再次缩放大图。

### ASR 语音增强（可选）

在插件配置中打开 **“启用 ASR 语音增强”**，下方才会显示 **“ASR 语音识别提供商”**。使用 AstrBot 原生选择器，从已配置的语音识别（STT/ASR）提供商中选择；保存并重载插件后生效。

- 开关关闭时不提取音频，也不调用 ASR。开启但未选择提供商，或所选提供商未加载、已禁用、类型不符时，仅分析画面，不自动选择其他模型。
- `video_overview` 尝试转写全片第一条音轨；`video_inspect` 获取与请求时间范围或时间点相交的音频片段。音轨按原视频时间轴每 **30 秒**分段，以 **16 kHz 单声道 WAV** 交给所选提供商。最后一段按视频时长截取，回看可能附带超出所选范围的完整音频段。
- AstrBot 通用 STT 接口只返回文本，因此 `asr.segments[].start_sec/end_sec` 表示**音频分段范围，不能视为逐字或逐句时间戳**。转写可能误识别，空转写也不证明没有说话或其他声音。
- 直接看图时，转写仅在工具结果的 `asr` 中提供一次，不再复制到 `user` 图片消息。指定概览看图模型时，该模型也会接收转写辅助观察，主模型仍能读取原始分段转写。两种图片输出模式均支持。
- 同一问题中已经提供的音频段不重复附加；新问题可从缓存读取。缓存按视频文件身份、ASR 提供商及其配置、模型区分，并沿用 `cache_ttl`、`cache_max_mb` 清理规则；密钥不写入缓存内容。临时 WAV 在成功、失败、超时或取消时删除。
- ASR 与抽帧、概览模型共用 `tool_timeout`，转写最多使用剩余时间的一半且不超过 **60 秒处理时间**，为画面处理保留预算；单次输出最多 **24000 字符**。时间不足、达到文本上限或中途失败时，通过 `status`、`complete` 和提示明确标记不完整结果，保留已经完成的转写及画面，不将部分转写当成全片记录。
- 聊天中的两个视频工具可自动附加转写；调试台可在“模型理解”中显式转写并测试。调试台的本地流水线、输入预览和状态轮询均不调用 ASR，只有点击“转写音轨”才会执行。远程 ASR 会按供应商配置发送音频并可能产生费用；本地 ASR 沿用 AstrBot 的运行环境。

### `video_inspect`

查看动作过程：

```json
{
  "video_path": "/AstrBot/data/temp/example.mp4",
  "mode": "range",
  "times_sec": [120, 124],
  "max_frames": 8,
  "max_edge": 768
}
```

核实指定时刻：

```json
{
  "video_path": "/AstrBot/data/temp/example.mp4",
  "mode": "timestamps",
  "times_sec": [120.5, 121.8, 123],
  "max_frames": null,
  "max_edge": 1280
}
```

`mode` 必须明确选择 `range` 或 `timestamps`：前者的 `times_sec` 恰好包含起止时间，后者为非空时间点列表。工具 Schema 显式声明模式枚举、必填字段和可为空的可选参数；`max_frames`、`max_edge` 填 `null` 使用插件配置值，不填 `0` 或空数组占位。

旧的 `start_sec`、`end_sec`、`timestamps_sec` 调用格式已移除，没有兼容别名；已有工具调用脚本需要改用 `mode`、`times_sec`。升级后重载插件，并在新问题中调用以使用更新后的工具定义。

所有时间以原视频时间轴为准，从 0 秒开始；实际帧可能略晚于请求时间，尾部可能回退至可读取的帧，因此应以返回的 `timestamp_sec` 为准。重复落到同一帧时只返回一次。参数错误返回 `INVALID_ARGUMENT`、正确调用示例和剩余回看次数，不消耗抽帧额度；处理失败或超时仍计入次数。

`max_edge` 是模型请求的图片最长边上限，保持比例、不放大小图，并受服务端硬上限约束。查看小字可以提高尺寸；没采到动作过程则应缩小时间范围或增加采样帧数。同一问题内已返回的相同尺寸、相同画面帧不会重复送图，相同视频概览也不会重复生成。

## 流水线调试台

在支持原生插件页面的 AstrBot WebUI 中，重载插件后打开 **视频理解 → 视频流水线调试台**，上传视频，再逐次点击右上方的执行按钮：

```text
视频探测 → 场景检测 → 两路候选 → 候选预合并 → 抽帧与压缩 → 邻近去重 → 最终输出 → 模型理解（可选）
```

- 每次点击只执行下一个阶段；已完成的阶段可随时切换查看。页面与 `video_overview` 共用同一条处理流水线。
- 场景检测展示变化分数、阈值及窗口取舍。长视频曲线最多保留 2000 个时间窗的峰值；阈值候选明细最多记录前 4000 条，实际筛选仍处理全部候选。
- 两路候选分别展示固定间隔及首尾帧、场景变化帧，并共用视频时间轴。候选小图按需额外抽取，长边最多 240 像素；正式抽帧发生在预合并之后。
- 正式抽帧展示请求及实际时间、输出尺寸、JPEG 体积。点击图片可查看压缩结果、实际去重指纹，并按需加载原分辨率 JPEG 对照。场景检测的 `160×160` 缩放、正式输出的长边限制、`32×18` 灰度指纹分别解释。
- 邻近去重可逐对查看画面差异、质量分、时间覆盖上限和保留原因。最终结果展示来源统计、最大时间空隙、图片总体积，并支持导出 JSON 调试记录。
- 可选择独立帧或九宫格后重跑；最终输出展示实际发送图片数、总像素、输出体积和九宫格预览。点击拼图可切换原始像素查看，核对每格的帧编号、实际时间和尺寸。
- 第八阶段 **“模型理解”** 可选择 AstrBot 已配置的看图模型、输入测试问题，并独立选择本次使用独立帧还是九宫格。两种图片模式复用同一批最终保留帧，切换不重新抽帧，也不改变全局配置。已明确关闭图片输入的模型不会出现在列表中；未标注图片能力的模型会提醒需自行确认支持。
- 可勾选 **“加入 ASR 语音转写（仅本次测试）”**，选择已启用的语音识别提供商，再点 **“转写音轨”**。页面展示分段范围、转写文本、耗时和缓存命中；先确认转写，再预览并调用看图模型。默认继承插件 ASR 配置，本次选择不修改全局配置；切换图片模式复用转写，关闭此项可用相同画面和问题进行对照。转写复用聊天工具的分段、缓存和时间预算，支持取消与重试；无音轨或转写失败时仍可测试画面。
- 先点 **“预览模型输入”**，查看实际输入图片、尺寸、体积、帧时间戳，以及完整系统和用户提示词；再单独点 **“调用模型”**。前七步、输入预览及查看历史都不会调用模型。页面复用聊天工具中指定概览模型的提示词与调用入口，不附加人设、聊天历史或工具。
- 调用后展示回答、耗时及 AstrBot 返回的输入、输出、缓存输入与总 token 用量；未提供的字段显示 **“未提供”**，不估算视觉 token。每次调用保存模型、问题、图片模式、是否加入 ASR、实际输入和结果，可选两条记录并排比较，也可导出包含转写记录的全部 JSON。普通状态轮询不重复传输转写原文、完整提示词和回答。
- 支持取消、失败重试和页面刷新后恢复记录；重复提交同一个调用或转写编号不会重复执行。每个测试会话最多保留 **20 条模型调用记录和 20 条转写记录**，重跑本地流水线会清空记录和旧图片，可先导出留存。
- 切换 WebUI 页面或刷新后，自动恢复上次测试、查看阶段、参数、模型问题与 ASR 选项草稿、分页、去重比较位置和选中的调用记录；后台任务继续执行，输入预览恢复时不会调用模型或 ASR。页面状态通过插件后端按管理员保存，与测试会话一同过期或清理。若需继续播放源视频，可重新选择原文件关联本地播放器，无需再次上传或重跑。
- 左侧参数只用于本次测试，应用后从头重跑；支持取消当前阶段、恢复仍有效的测试会话，以及手动删除。重跑清理旧调试图片，防止旧页面或旧参数混入新结果。

调试台仅供已登录的 WebUI 管理员使用，模型调用使用所选模型的已配置凭据。视频上传限制为 **256 MiB**，全局最多保留 **4 个测试会话**；每个会话的图片缓存上限为 `cache_max_mb` 与 **512 MiB** 中较小者。测试文件闲置 `cache_ttl` 秒后清理（最长 1 小时），插件卸载或重载时清理本次测试文件和记录，不删除聊天中提供的源视频。本地处理、额外预览及每次模型调用分别计时；本地处理共用 `tool_timeout` 时间预算，每次模型调用单独使用该超时，均不计手动查看阶段的停顿。调用失败或取消后保留本地帧；供应商可能已经处理请求，是否计费以供应商为准。

## 配置

| 配置 | 默认值 | 用途 |
|---|---:|---|
| `ffmpeg_path` / `ffprobe_path` | 空 | 留空从 PATH 查找 |
| `allowed_video_roots` | `[]` | 额外允许读取的已有绝对目录 |
| `overview_provider_id` | 空 | 概览看图模型，使用 AstrBot 已配置模型的选择器；留空由主模型直接看图 |
| `asr_enabled` | `false` | 启用 ASR 语音增强，并显示提供商选择项 |
| `asr_provider_id` | 空 | 从 AstrBot 已配置的 STT/ASR 提供商中选择；开启且所选提供商可用时启用转写 |
| `overview_output_mode` | `frames` | `frames` 独立帧；`grid` 每组最多 9 帧无损拼接，仅影响概览 |
| `overview_interval` | 4 | 概览默认间隔，单位秒 |
| `overview_max_frames` | 200 | 概览总帧数上限 |
| `overview_max_edge` | 640 | 概览图片长边像素上限 |
| `scene_threshold` | 0.3 | 场景变化阈值，越低越敏感 |
| `inspect_max_frames` | 8 | 单次回看帧数硬上限 |
| `inspect_max_edge` | 768 | 回看默认图片长边上限 |
| `max_edge_limit` | 1280 | 所有单帧尺寸请求的长边硬上限，九宫格保留各帧尺寸、不额外缩放 |
| `inspect_max_calls` | 3 | 单个问题的回看次数上限 |
| `tool_timeout` | 300 | 单次工具总超时，单位秒 |
| `max_concurrency` | 2 | 工具及子进程并发上限 |
| `cache_ttl` | 3600 | 缓存闲置期限与视频授权期限，单位秒 |
| `cache_max_mb` | 512 | 空闲清理后的缓存容量上限，单位 MB |

配置项和服务端上限可按模型能力调整。**200 帧是帧数预算，不是 token 上限，也不保证所有模型接口都能接收。**独立帧每帧一张图片，九宫格每组最多 9 帧一张图片。如果模型限制图片数量、图片尺寸或上下文长度，请调整输出模式和概览预算。缓存可减少本地解码开销，不代表新问题里的图片输入不计费。

指定概览模型后，图片 token 开销转移到所选模型，主模型还会消耗文字概览及局部回看的 token。选择更便宜的看图模型可能降低费用，但多出一次模型调用，不保证总费用更低或速度更快。

## 文件和权限边界

- 仅接收本地视频路径，不通过工具下载网址，也不支持 B 站链接或网络共享路径。视频附件的落盘由 AstrBot 消息组件负责。
- 默认允许 AstrBot 的 data、temp 目录。其他位置需要加入 `allowed_video_roots`；路径会规范化并检查真实位置，不能通过 `..` 或符号链接逃出允许目录。
- 普通用户只能访问自己在同一会话提供、且仍在授权有效期内的视频；更换用户或会话不能借用该路径。管理员可直接传入允许目录内的视频路径。
- 文件发生变化后，普通用户需要重新发送以授权；缓存按路径、大小和修改时间区分。
- 使用参数列表调用 FFmpeg，不拼接 Shell 命令；解码限定本地协议及常见视频容器，不接受播放列表作为输入。
- 只清理插件自己的图片、音频和转写缓存，不删除源视频。上游必须保证回看时源文件仍存在；插件重载会清空会话授权，必要时请重新发送视频。
- 视频内容是不可信资料，不能当作系统或工具指令。稀疏采样没有看到某事件，不足以证明事件没有发生；预算耗尽仍不确定时应明确说明。

支持可选 ASR 语音转写和概览看图模型，不包含专门的字幕 OCR、语义搜索或额外的多级视觉分析流水线。
